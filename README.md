# CRIME IN NEW ZEALAND

This  project focuses on crime in New Zealand and how drug/drink driving behavour has changed through past decades.  

## OBJECTIVE

To investigate how drink/drug driving behvious has changed within the past two decades. Through this analysis I am alspo exploring other factors given the data that i am working with such as different regions in New Zealand and conviction rates.

## DATA
>  Data was collected from the Aotearoa Data Explorer (StatsNZ) which is public data.

'Outcomes' show the different outcomes in court for drug/drink driving behaviour as follows:
- 'Convicted': only charges finalised in the District or High Court can result in a person being convicted.
- 'Other proved': these charges are not recorded as convictions, and include charges where:
- 'Not proved': includes the person being found not guilty and where the charge was dismissed, discharged, withdrawn, or other not proved outcomes
- 'Other': includes outcomes such as where there was a stay of proceeding, the person was found unfit to stand trial, the person was found not guilty by reason of insanity and an order was made.

## METHODOLOGY

 - Restructured data using power query
 - Cleaned data set
 - Used pivot tables
 - Built dashboad with slicers

## KEY FINDINGS

- Exponential growth for 'other proved' in the past decade
- Slight dip in convicted behaviour around 2020-2022 as expected (covid era)
- High conviction behaviour in the Northland region
